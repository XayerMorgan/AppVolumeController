# Release files

Download ready-to-run builds from [GitHub Releases](https://github.com/XayerMorgan/AppVolumeController/releases).

Run `Build.ps1 -Installer -Verify` to create a versioned setup EXE, a portable ZIP, offline help, the MIT license, a testing guide, and `SHA256SUMS.txt` here.

Share the **Setup.exe** and **TESTING.txt** with testers. The ZIP is an optional alternative: extract its entire contents before running the app. Build intermediates and verification screenshots belong in `artifacts`, not in this folder.
