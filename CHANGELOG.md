# Changelog

## 0.1.0-beta.2 — First public beta

- Published the Windows mixer with per-app volume/mute, favorites, search, and optional remembered settings.
- Added an offline HTML user guide with a Help button, F1 shortcut, and Start menu help shortcut.
- Included light, dark, system, and high contrast themes, preset/custom accent palettes, and 100–200% text sizing.
- Added public installation, troubleshooting, contributor, and source-build instructions.
- Added MIT licensing, GitHub issue templates, and Windows build/compatibility checks.
- Distributed a self-contained per-user installer and portable ZIP with checksums and third-party notices.

## 0.1.0-beta.1 — Local testing build

- Introduced installer packaging, Start menu/optional desktop shortcuts, and uninstall support.
- Organized source, tests, scripts, documentation, and generated outputs.
- Verified local install, startup, reinstall, uninstall, and preservation of existing preferences.
