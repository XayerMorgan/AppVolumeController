Get started

You need Windows 10 22H2 (build 19045) or Windows 11 and a playback device. Intel/AMD 64-bit PCs are tested. Windows on ARM is unverified. The installer and portable package include .NET, so no separate runtime installation is needed.

  1. Download the Setup.exe from the official releases page. GitHub's automatically generated “Source code” archives are for developers.
  2. Run the installer. It installs for your account and offers an optional desktop shortcut.
  3. Open App Volume Controller from the Start menu.
  4. Play audio in an app. It should appear within about three seconds; choose Rescan to check immediately.
  5. Adjust that app's slider or toggle Mute.
About this beta

The release is unsigned, so Windows may show an unknown-publisher or SmartScreen warning. Check that your download comes from the official repository before deciding whether to run it. Do not disable Windows security protections to install the app.

Prefer a portable copy?

Download Portable.zip, extract the entire archive, then run AppVolumeController.exe. Keep its files together. It stores preferences in the same location as the installed version.

Volume controls

  • Application sliders: set an app's volume from 0% to 100%. Changing volume does not clear mute.
  • Mute / Muted: a checked box and the word “Muted” mean mute is enabled. Clear it to restore sound.
  • Favorite: keeps an app near the top. Sorting waits until keyboard focus leaves the app cards so the control you are using stays in place. Black Desert Online and Discord are favorites by default.
  • Find an app: filters by name. Clear removes the search text; “Favorites only” is a separate filter.
  • Master output: controls your current Windows default multimedia playback device. Per-app rows can include sessions on other active playback devices.
  • Remember my volume changes: restores volume and mute values you changed here when apps create new sessions. It is off by default. Enabling it does not immediately overwrite already connected sessions.

One app, several sessions

Sessions with the same executable name are grouped, including sessions on different devices. A slider change applies to all of them. The displayed volume comes from the first session. “Different volumes” or “Some muted” indicates a mixed state; the mute checkbox is checked only when all grouped sessions are muted. Moving the slider aligns the session volumes.

The list refreshes automatically. Quiet apps may remain visible while their audio sessions still exist. Automatic refresh pauses during dragging and briefly after keyboard adjustments.

Appearance and accessibility

Choose Appearance or press Ctrl + ,.

  • Theme: System follows the Windows app theme; Light, Dark, and High contrast provide explicit choices. Active Windows high contrast always takes priority and uses your system colors.
  • Accent palette: choose Teal, Blue, Violet, Amber, or Custom. Custom colors use a hash plus six hexadecimal digits, such as #14B8A6. Choose Apply color to preview.
  • Readable colors: the app adjusts the displayed accent shade for contrast in each theme. The preview shows the effective color; your requested custom color remains saved.
  • Text size: choose 100%, 125%, 150%, or 200%. Windows display scaling also applies; scroll to reach content at larger sizes.

Changes preview immediately. Save changes keeps them. Cancel, Esc, or closing the dialog restores the previous appearance. Reset appearance previews defaults; save to keep the reset. Audio settings and favorites are not reset.

Controls have keyboard focus indicators and application-specific screen-reader labels. Mute and favorites use checkmarks and text as well as color. There are no interface animations. Hands-on screen-reader and multi-monitor scaling feedback is welcome.

Troubleshooting

An app is missing

Play audio in that app, clear the search, turn off Favorites only, then choose Rescan. The app must create a Windows playback session. Microphones and applications using exclusive-mode audio are not controlled here.

The slider moves but I cannot hear sound

Check the app's Mute checkbox, master output mute and volume, the app's own volume, and the selected Windows output device. The per-app slider does not automatically unmute an app. An app may be playing through a different output from the default device shown in Master output.

A device is unavailable or the output changed

Reconnect the device or choose a working output in Windows Sound settings, then rescan. The master label follows the default device. When no default device is available, master controls are disabled.

My volume settings came back after restarting an app

If Remember my volume changes is enabled, saved values are restored for new sessions. Turn it off to stop restoration. This does not delete saved values or immediately alter existing sessions.

A custom accent looks lighter or darker than the color I typed

The app adjusts its displayed shade to keep text and controls readable. The requested color is retained, while the palette preview shows the effective shade. Windows high contrast overrides custom accents.

Settings cannot be saved

The app needs write access to %LOCALAPPDATA%\AppVolumeController. Check available disk space and that folder's permissions. An inline error means the current changes may not survive a restart. Appearance stays open after a save error so you can retry or cancel.

The portable app does not start

Extract the complete ZIP before launching the executable; copying only the EXE leaves out required runtime files. Check the Windows requirements above. If it still fails, report the exact error and release version.

Help does not open

Open HELP.html in the app's installation folder with a browser, or read the online user guide. If the file is missing, reinstall or re-extract the complete portable archive.

Your settings, updates, and removal

Favorites, remembered volume/mute values, and appearance preferences are stored in %LOCALAPPDATA%\AppVolumeController\preferences.json. The file contains application identifiers and settings. You can copy it as a backup while the app is closed.

To update, close the app and run the newer installer. To remove it, use Windows Settings → Apps → Installed apps → App Volume Controller (Apps & features on Windows 10). Uninstall keeps your preferences for a later reinstall. To reset all settings deliberately, close the app and rename preferences.json to preferences.backup.json; the next launch uses defaults.

The app works locally and does not upload your app list or settings. It installs no background service, startup task, telemetry, or automatic updater. Closing the window stops the app. The user guide opens locally; following GitHub links uses your browser's internet connection.

Get help or contribute

For a bug or accessibility issue, use the GitHub issue forms. Include the app version from your download, Windows version, installation type, relevant app/output device, reproduction steps, and expected versus actual behavior. For accessibility issues include the screen reader, text size, and display scaling. Omit private audio, passwords, and full preferences files.
